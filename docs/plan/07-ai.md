# 07 — AI (M6; presentations in M8)

The web app uses the **cloud AI** of the Writeopia backend (Gemini). Every call is a normal
authenticated API request; usage counts against the user's token quota.

Reference: `Writeopia/application/core/genai/` (`GenAiApi.kt`, `GenAiRepository.kt`),
`application/features/editor/.../viewmodel/` (`AiCommandService.kt`, `AiCommandContext.kt`,
`DocumentRewrite.kt`, `PromptService.kt`), `.../ui/ai/` (`AiCommandBar.kt`, `AiOptionsTabs.kt`),
`application/features/writing_agent/`, `common/endpoints/.../dto/`,
`backend/core/ai/.../routing/`. Swift: `AiAPI.swift`, `AiPrompts.swift`, `DocumentRewrite.swift`,
`WritingAgentController.swift`.

Endpoint shapes are in [02](02-api-and-data.md#ai-ai).

## Availability, tiers and usage

- `GET /api/ai/status` on entering the app; if unavailable, AI entry points are hidden or
  disabled with an explanation.
- Premium-gated calls answer with an error for FREE users → show the premium dialog.
- `GET /api/ai/usage` → tokens used vs quota, shown in Settings → AI ([08](08-settings.md)) and
  refreshed after each AI call.
- Model picker: the side panel shows "AI model" when the backend offers a choice; send the
  selection as `model` (omit for the default).

## Streaming

`stream: true` answers arrive as server-sent-event lines `data: {"response": "...", "done":
false}`; the last has `done: true`, and `error` may be set. Read with `fetch` +
`ReadableStream` + `TextDecoder` (not `EventSource`, which cannot POST). Expose an async
iterator and an `AbortController` so the user can cancel.

## AI command bar

A text field ("Ask AI…") opened from the selection toolbar, the side panel, or the shortcut.

1. Collect context (`AiCommandContext`): the command, the selected text (selected blocks or text
   selection), document title, document text.
2. `POST /api/ai/command-intent` → `REPLACE` | `ADD` | `REWRITE`.
   - `REPLACE`: the answer replaces the selected lines (rewrite, fix, translate).
   - `ADD`: the answer is new content inserted below.
   - `REWRITE`: nothing selected — the whole document comes back rewritten.
3. `POST /api/ai/command` with that `intent`, streamed.
4. While streaming: replaced blocks show as **skeleton** blocks (type 25, ephemeral, holding the
   original text so it can be restored); added content streams into AI blocks.
5. The result is a **suggestion** (`AI_SUGGESTION` / `FIRST_AI_SUGGESTION` tags): accept (button
   or shortcut) turns it into normal blocks; reject restores the original.

`REWRITE` protocol (`DocumentRewrite.kt`): the document is sent as Markdown, one paragraph per
line, and blocks the AI cannot handle (images, drawings, spreadsheets…) are replaced by
`[[writeopia-block-N]]` placeholder lines that must be mapped back afterwards. Long documents are
cut around the selection (`documentAround`). Port this file together with its tests.

AI output is Markdown; convert it to blocks with the same Markdown → steps parser used for paste
and import (`writingagent/actions/MarkdownList.kt`, `MarkdownTable.kt`, `MarkdownCode.kt`).

## Quick actions

Side panel → AI tab. Target selector "Apply to": **Document** or **Selected lines** (the cursor
target is hinted as unavailable for quick actions).

| Action        | Endpoint                     | Result                         |
| ------------- | ---------------------------- | ------------------------------ |
| Summary       | `POST /api/ai/summary`       | Inserted as AI answer block(s) |
| Action points | `POST /api/ai/action-points` | Checklist                      |
| FAQ           | `POST /api/ai/faq`           | Q&A blocks                     |
| Tags          | `POST /api/ai/tags`          | Tag suggestions                |

Prompts are built on the client from the target text — port `PromptService.kt`.
"Select lines first" is shown when the target is selected lines and nothing is selected.

## Writing agent

Proactive suggestions while writing (`WritingAgentController.kt`):

- Trigger when a sentence ends in the paragraph being written (`SentenceEnds.kt`), debounced,
  and once when a document is opened (`scope: DOCUMENT_OPENED`).
- `POST /api/ai/writing-suggestions` → actions with probabilities; show the top ones in a small
  box next to the block (`WritingSuggestionsBox.kt`).
- Actions: code block, list, checklist, new linked document, image, drawing, spreadsheet,
  section heading, callout, TL;DR, conclusion. `DOCUMENT_TITLE` is decided locally: offered when
  the document has text but no title.
- Accepting runs the matching editor action, some of which call `/api/ai/generate` to produce
  content (`WritingActionExecutor.kt`, `AiTextWriter.kt`).
- Dismissed suggestions are not offered again for that paragraph.

Folder and tag suggestions:

- Document in the root folder → `POST /api/ai/folder-suggestions` (send `workspaceId`; the backend
  ranks folders itself) → dialog "Move to <folder>?" (`FolderSuggestionDialog.kt`).
- Document without tags → `POST /api/ai/tag-suggestions` with up to 30 catalogue tags → dialog to
  apply them (`TagSuggestionDialog.kt`).

## Image for a paragraph

`POST /api/ai/image` `{paragraph, documentTitle, documentText}` → `{imageUrl}` → insert an image
block below the paragraph (loading block meanwhile).

## Presentations (M8)

Reference: `application/features/editor/.../features/presentation/`.

- Dialog on a document: list (`GET …/document/{id}/presentations`), generate
  (`POST` same path, `{model?}` → 201 `{presentation}`), delete.
- Viewer: slides (`{title, content: StoryStep[]}`) rendered with the read-only block components,
  next/previous with arrow keys, full screen via the Fullscreen API.
- Route `/app/presentation/:presentationId`.
- Presentations also appear in search results.
